# 本次分析执行约定

在拟合任何新模型前记录以下约定。延续2026年11月9日方案v1.0，主分析按编号特征开展课程探索。

1. 尚无官方字典和事件单位，不把推定临床名称当作已证实事实。主结果不应用依赖猜测单位的临床范围删除规则，保留原CSV数值；所有图表同时列出字段编号。另按现有代码的推定单位执行宽范围筛查敏感性分析，明确其条件性。
2. 临床单位OR不具备报告条件。补充展示固定C惩罚模型的标准化系数及1000次开发集bootstrap稳定性区间，连续项统一换算至主开发集1个标准差，二分类项按0到1；不解释为病因或治疗效果。
3. 年龄、性别及8个数值字段完全按方案指定。M0至M3及补充梯度提升模型使用同一80/20分层患者划分。所有插补、缩放、训练集分位数和特征变换均在各训练折拟合。
4. 2000次测试患者配对bootstrap用于固定模型的Brier、AUROC、AP和模型间差值区间。校准截距斜率作为点估计，校准图分组事件率给Wilson区间。
5. 预设敏感性分析包括全部住院的患者分组验证、排除0近似月龄、完整候选病例、训练分位数缩尾、年龄样条、排除>=216近似月龄边界记录，以及推定单位下的宽范围筛查。缩尾作为数值稳健性检查，不声称确定了检验单位。
6. 不使用本轮测试结果修改主要模型或选择变量，不以敏感性分析最佳表现替换主结果。敏感性分析沿用主模型已选C，以减少重复选模，属于固定超参数的稳健性分析，不是每个人群的最优模型竞赛；该实施细化在拟合前记录。
7. 网页报告仅展示汇总结果；划分与预测明细保存在private目录，不进入对外分享压缩包。
8. 本轮交付分析结果、图表、可复现代码和阶段性结果报告。LaTeX课程终稿与项目展示网站属于后续整合，不将HTML阶段报告称为LaTeX导出PDF。
