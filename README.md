我在公共卫生领域学习和研究，关注心血管疾病及其与代谢、肾脏健康的联系。我感兴趣的两个问题是：**如何利用患者随时间积累的诊疗信息，更准确地评估未来风险？如何利用常规医疗数据，可靠地比较不同治疗策略的效果？

研究方向 / Research Interests

- 纵向医疗数据与风险预测。 我关注如何从电子健康记录中提取有用的纵向信息，将病程、检验和治疗变化纳入患者表征。我也在探索机器学习和语言模型能否改善风险估计，以及模型在不同人群中的校准表现。
- 真实世界证据与治疗策略评价。 我关注如何运用因果推断和目标试验模拟研究心血管疾病的治疗策略，尤其是如何定义治疗起点、处理随时间变化的用药信息，以及理解不同患者群体之间的获益差异。
